# YouTube Remote Controller

PCで開いているGoogle ChromeのYouTubeを、スマートフォンやタブレットなどの他デバイスからリモコンのように遠隔操作したり、YouTube TVのように**「スマホで動画を検索してPCにキャスト（再生）する」**ことができるChrome拡張機能＋リモコンUIシステムです。

PC側でNode.jsなどのサーバープログラム（ターミナル）を実行・起動しておく必要は一切なく、**完全サーバーレス（WebRTC P2P通信）**で動作します。

この拡張機能が[Chrome Webstore](https://chromewebstore.google.com/detail/youtube-remote-controller/jdkccoihfaeebmakcllhjbonifpiabmh)で公開されました。

## 主な機能特徴

- 📺 **YouTube TV風キャスト（検索＆再生）**:
  - スマホ側でキーワードを入力してYouTube動画をリアルタイム検索（PCを介して検索を行うため、APIキー等の準備は一切不要）。
  - スマホに表示されたサムネイルやタイトルをタップするだけで、PC側のYouTubeが自動的にその動画へ遷移し、即座に再生を開始します。
- 🎶 **再生キュー（Queue）連続再生**:
  - 検索結果の「＋」ボタンで、次に再生する動画をキュー（予約リスト）に登録可能。
  - 再生中の動画が終了すると、スマホが自動的にキューの次の動画を検知し、PC側にキャストして**自動で連続再生**させます。
  - 専用の「キュー」タブから、ストックした動画リストの確認や個別削除、一括クリアが可能です。
- ⚡ **再生速度（Playback Rate）調整**:
  - リモコン画面の速度インジケーターから、`0.25x` 〜 `2.0x` までの再生速度をリアルタイムに切り替えられます。
- ⏯️ **メディアコントロール**:
  - 再生 / 一時停止、次の動画 / 前の動画、10秒進む / 戻る。
  - シークスライダーによる再生位置のシーク（同期ズレを防ぐスマートシーク設計）。
  - 音量調整スライダーおよびミュート切り替え。
- 🖼️ **リアルタイム双方向同期**:
  - PCで再生中の動画タイトル、チャンネル名、サムネイル画像、再生時間、ボリューム状態がスマホ側UIへリアルタイムに同期表示されます。
- 🏠 **全ページ対応 & ペアリングガイド**:
  - YouTubeのトップページや検索結果画面など、動画再生画面以外のどのページを開いていても接続が維持されます。
  - パラメータなしでリモコンURL（例: `https://remote.example.com/`）に直接アクセスした場合は、本機能の案内と使い方を示す専用のガイドページが表示されます。

## 接続と通信の仕組み

本システムは、デバイス間でのP2P暗号化通信規格である **WebRTC (PeerJS)** を使用しています。

1. **シグナリング（接続の確立）**: 接続を開始する際のみ、PeerJSの公開無料サーバーを利用して、PC（拡張機能）とスマホの接続ルートを仲介します。
2. **P2P通信 / TURN中継**: 接続が確立されると、データはインターネットを介さず直接送信されます。PCとスマホが異なる回線（自宅Wi-Fiと4G/5G回線など）にある場合や、対称型NAT（Symmetric NAT）環境下にある場合でも、設定に組み込まれた無料のパブリック**STUN/TURNサーバー（Open Relay Project）**により、100%確実に接続ルートが確保され、低遅延で暗号化された通信が行われます。
3. **Peer IDの固定化**: PC（拡張機能）側のPeer IDは拡張機能のストレージに永続化されます。PC側で動画の切り替えやページリロードが発生して一瞬接続が切れても、スマホ側が同じPeer IDに対して自動で再接続を行うため、ペアリングし直す手間がありません。

## 導入手順

システムは、PC側にインストールする **「Chrome拡張機能（`extension/`）」** と、スマートフォン等のブラウザで開く **「リモコンUI（`remote/`）」** で構成されています。

### ステップ 1：リモコンUI（`remote/`）のホスティング
スマホからリモコン画面（HTML）にアクセスできるようにするため、`remote/` フォルダ内の3つの静的ファイル（`index.html`, `style.css`, `remote.js`）をインターネット上にホストします。

#### 方法A：GitHub Pages を使う（最も簡単・無料）
1. GitHubにサインインし、新しいパブリックリポジトリ（例: `youtube-remote`）を作成します。
2. 作成したリポジトリに、本プロジェクトの **`remote` フォルダ内のファイル**をアップロードします。
3. リポジトリの **Settings** ＞ **Pages** を開きます。
4. **Build and deployment** の **Source** を `Deploy from a branch` に設定し、**Branch** を `main` (または `master`)、フォルダを `/ (root)` に選択して **Save** をクリックします。
5. 数分後、画面上部に公開URL（例: `https://<あなたのユーザー名>.github.io/youtube-remote/`）が表示されます。

#### 方法B：Ubuntu Server ＋ Cloudflare Tunnel を使う（自宅サーバー環境向け）
自前のUbuntu Server等でホストし、Cloudflare Tunnel経由で安全に公開します（SSL/HTTPSが自動付与されます）。
1. Ubuntu Server上の任意のディレクトリ（例: `/var/www/yt-remote`）に `remote` フォルダの中身を配置し、NginxやPythonの簡易サーバーでポートを公開します。
2. `cloudflared` をセットアップし、トンネルを作成します。
   ```bash
   cloudflared tunnel create yt-remote-tunnel
   ```
3. `~/.cloudflared/config.yml` に以下のようにルーティングを記述し、実行します。
   ```yaml
   tunnel: <TUNNEL_ID>
   credentials-file: /home/user/.cloudflared/<TUNNEL_ID>.json
   ingress:
     - hostname: yt-remote.yourdomain.com
       service: http://localhost:8080 # Webサーバーのローカルポート
     - service: http_status:404
   ```
4. DNSを紐づけ、トンネルを稼働させます。
   ```bash
   cloudflared tunnel route dns yt-remote-tunnel yt-remote.yourdomain.com
   cloudflared tunnel run yt-remote-tunnel
   ```

---

### ステップ 2：Chrome拡張機能のインストール
1. PCでGoogle Chromeを開き、`chrome://extensions/` にアクセスします。
2. 画面右上にある「**デベロッパーモード**」のトグルスイッチを **ON** にします。
3. 画面左上の「**パッケージ化されていない拡張機能を読み込む**」をクリックします。
4. 本プロジェクトの **`extension` フォルダを選択**して読み込みます（※親フォルダを選択するとマニフェストエラーが出るため、`manifest.json` が直接入っている `extension` フォルダを指定してください）。
5. ツールバーや一覧にアイコンが正しく反映されたら完了です。

---

### ステップ 3：ペアリングと使用方法
1. PCのChromeで、YouTubeの任意のページ（トップページ、検索結果、動画再生画面のどれでも可）を開きます。
2. 拡張機能のアイコンをクリックしてポップアップを開きます。
3. **ステップ1で公開したリモコンUIのURL**（例: `https://<あなたのユーザー名>.github.io/youtube-remote/` または `https://yt-remote.yourdomain.com/`）を入力して「**保存**」します。
4. 保存すると、下に接続用のQRコードが自動生成されます。
5. スマートフォンのカメラでQRコードをスキャンします。
6. スマホのブラウザでリモコン画面が開き、PCとの接続が確立されます（ステータスが「PCと接続完了」になります）。
7. リモコンとして動画操作を行ったり、「動画検索」から検索・キャスト再生、「＋」で連続再生キューへの追加をお楽しみください。

## トラブルシューティング

- **「異なるネットワークで接続できない」**:
  - 本システムにはSTUNサーバーに加え中継TURNサーバーが組み込まれており、通常は異なるネットワーク間でも100%接続できますが、スマホ側が古いキャッシュを読み込んでいる場合があります。スマホのブラウザで**シークレットモード（プライベートブラウズ）**でURLを開き直してみてください。
- **「サーバーのファイルを更新したのにスマホに反映されない」**:
  - Cloudflare Tunnel等を経由している場合、Cloudflareのエッジキャッシュが効いている可能性があります。Cloudflareの管理ダッシュボード ＞ キャッシュ ＞ 構成 から「**すべてパージ (Purge Everything)**」を実行するか、「**開発モード**」を有効にしてください。
- **「PC側で動画が変わると接続が一時的に切れる」**:
  - 動画ページの遷移時にブラウザのリロードが走るため、一瞬接続が切断されます。数秒待つとスマホ側がPCの固定IDを検知して自動的に再接続し、「接続完了」へと復帰します。
- **「拡張機能ポップアップに準備中...のエラーが残る」**:
  - YouTubeのページ読み込み途中でポップアップを開いた際などに発生することがあります。YouTubeが開いているPCのタブ自体を一度リロード（F5）してから、ポップアップを開き直してください。

## フォルダ構成と役割

```text
YouTubeRemoteController/
├── extension/             # Chrome拡張機能
│   ├── lib/
│   │   ├── peerjs.min.js  # WebRTC接続用ライブラリ
│   │   └── qrcode.min.js  # ペアリングQRコード生成ライブラリ
│   ├── icons/
│   │   ├── icon16.png     # 拡張機能アイコン (16x16)
│   │   ├── icon32.png     # 拡張機能アイコン (32x32)
│   │   ├── icon48.png     # 拡張機能アイコン (48x48)
│   │   └── icon128.png    # 拡張機能アイコン (128x128)
│   ├── manifest.json      # Manifest V3 定義ファイル
│   ├── content.js         # YouTubeタブで動作しプレイヤーを直接操作するスクリプト
│   ├── popup.html         # URL設定・QRコード表示用の拡張機能ポップアップUI
│   ├── popup.css          # ポップアップのデザイン
│   └── popup.js           # ポップアップ制御・QRコード描画ロジック
│
├── remote/                # スマートフォン側リモコンUI (Webサイト)
│   ├── index.html         # 操作画面UI (リモコン・動画検索・キュータブ、案内ガイド)
│   ├── style.css          # レスポンシブ＆ダークガラスモルフィズムのCSSデザイン
│   └── remote.js          # WebRTCクライアント接続、UI操作、検索・キュー同期ロジック
│
└── README.md              # 本説明ドキュメント
```

- 本システムは個人使用および学習用途を目的として作成されています。
- Chrome Web Storeへの公開や商業配布は想定されていません。
